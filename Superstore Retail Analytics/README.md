# Superstore Retail Analytics

A Power BI dashboard delivering a comprehensive performance analysis of a superstore retail chain across sales, categories, and geographies.

## Overview

This project provides an end-to-end view of retail operations using a large superstore dataset. It surfaces key metrics around revenue, category performance, customer segments, and geographic distribution to support retail strategy and operations teams.

## Project Structure

```
Superstore Retail Analytics/
├── SuperStore_Sales_Dataset.csv               # Main retail dataset (1.4 MB)
├── Superstore_Retail_Performance_Analyzer.pbix  # Power BI dashboard
├── snapshot.jpg                               # Dashboard preview
└── blue gradient.jpg                          # Dashboard background asset
```

## Key Insights

- **Revenue Summary** — Total sales, profit, and order volume at a glance
- **Category Breakdown** — Performance across Furniture, Office Supplies, and Technology
- **Geographic Analysis** — State and region-level sales distribution
- **Customer Segments** — Revenue split across Consumer, Corporate, and Home Office segments
- **Shipping Modes** — Order volume and profitability by shipping class

## Tools & Technologies

| Tool | Purpose |
|------|---------|
| Power BI | Dashboard creation and visualization |
| CSV | Raw retail sales data |

## Data Source

`SuperStore_Sales_Dataset.csv` — Contains detailed order records including order date, ship mode, customer segment, region, category, sub-category, sales, quantity, discount, and profit.

## How to Use

1. Open `Superstore_Retail_Performance_Analyzer.pbix` in Power BI Desktop
2. The CSV data is embedded — no additional setup required
3. Use slicers to filter by region, category, segment, or date range
