# Zomato Restaurants Analysis

A Power BI dashboard analyzing restaurant data from the Zomato platform to uncover insights about cuisine trends, ratings, pricing, and geographic distribution.

## Overview

This project dives into Zomato's restaurant dataset to help understand the food service landscape — identifying top-rated restaurants, popular cuisines, average cost patterns, and city-wise restaurant density. Useful for market research, franchise planning, and competitive analysis.

## Project Structure

```
Zomato Restaurants Analysis/
├── zomato_data.xlsx                  # Restaurant dataset (1.5 MB)
├── Zomato_Insights_Dashboard.pbix    # Power BI dashboard
├── snapshot.jpg                      # Dashboard preview
└── overview.pdf                      # Exported PDF report
```

## Key Insights

- **Restaurant Overview** — Total restaurants, average ratings, and cost distribution
- **Cuisine Analysis** — Most popular cuisines and their average ratings
- **Geographic Distribution** — Restaurant density and performance by city and country
- **Online vs. Offline** — Comparison of online-order-enabled vs. dine-in-only restaurants
- **Price Range Analysis** — Distribution of restaurants across cost brackets
- **Top Performers** — Highest-rated and most-voted restaurants

## Tools & Technologies

| Tool | Purpose |
|------|---------|
| Power BI | Interactive dashboard and visualization |
| Excel | Raw restaurant dataset |

## Data Source

`zomato_data.xlsx` — Contains restaurant-level records including name, location, cuisine type, average cost for two, online ordering availability, table booking, ratings, and votes.

## How to Use

1. Open `Zomato_Insights_Dashboard.pbix` in Power BI Desktop
2. Data is sourced from the included Excel file — ensure both files are in the same directory
3. Use filters to explore by city, cuisine, price range, or rating tier
