# Crypto Market Trends

A Power BI dashboard analyzing cryptocurrency price trends and market dynamics across multiple digital assets.

## Overview

This project tracks and visualizes historical price data for major cryptocurrencies, enabling trend analysis, comparative performance review, and market pattern identification.

## Project Structure

```
Crypto Market Trends/
├── CryptoData.xlsx                  # Consolidated cryptocurrency dataset
├── CryptoData CSV/                  # Individual CSV files per coin
│   ├── Bitcoin.csv
│   ├── Ethereum.csv
│   ├── BinanceCoin.csv
│   ├── Dogecoin.csv
│   ├── NEM.csv
│   ├── Stellar.csv
│   └── XRP.csv
├── CryptoCurrency_Dashboard.pbix    # Power BI dashboard
├── Dashboard_Snapshot.png           # Dashboard preview
├── Price_Trends_Analysis.png        # Price trend visualization
└── PDF Representation/              # Exported PDF report
```

## Key Insights

- **Price Trend Analysis** — Historical price movements for each cryptocurrency
- **Comparative Performance** — Side-by-side comparison across coins
- **Market Volatility** — Price fluctuation patterns and volatility metrics
- **Volume Analysis** — Trading volume trends over time

## Tools & Technologies

| Tool | Purpose |
|------|---------|
| Power BI | Interactive dashboard and visualization |
| Excel / CSV | Raw price data storage |

## How to Use

1. Open `CryptoCurrency_Dashboard.pbix` in Power BI Desktop
2. Data is sourced from the included CSV/Excel files
3. Use filters to select specific coins or date ranges for focused analysis
