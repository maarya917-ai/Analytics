# Electronic Store Sales Report — FY 2023

A Power BI dashboard delivering a full-year sales performance view for an electronics retail store, covering revenue, product mix, and customer purchase behavior across FY 2023.

## Project Overview

This project provides an end-to-end analysis of an electronics store's fiscal year 2023 performance. It is designed to support store managers and business stakeholders in understanding top-selling products, category contributions, and seasonal demand patterns throughout the year.

## Folder Structure

```
Electronic Store Sales Report/
└── Store FY 23.pbix    # Main Power BI dashboard with embedded data
```

## Key Insights

- **Revenue Performance** — Total sales, order volume, and average transaction value for FY 2023
- **Product Category Analysis** — Contribution of electronics sub-categories (e.g., phones, laptops, accessories) to overall revenue
- **Monthly Trends** — Month-over-month sales fluctuations to identify peak and off-peak periods
- **Top Products** — Best-selling items by units sold and by revenue generated
- **Customer Purchase Patterns** — Insights into order frequency and basket size

## Tools Used

| Tool | Purpose |
|------|---------|
| Power BI Desktop | Dashboard development, data modeling, and visualization |

## Data Sources

The dataset is embedded within the `.pbix` file and covers the full FY 2023 period for an electronics retail store. It includes transaction-level records with product, category, date, and revenue fields.

## How to Use

1. Open `Store FY 23.pbix` in Power BI Desktop.
2. The data is embedded — no external source connections are required.
3. Use the date slicer to narrow the view to specific months or quarters.
4. Apply category or product filters to drill into specific segments.
5. Use the export option in Power BI to share visuals as PDFs or PowerPoint slides.
