# Retail Store & Education Analytics

A multi-domain Power BI project combining retail sales analysis with education sector data, covering superstore performance, student survey insights, and university admissions trends.

## Project Overview

This project brings together datasets from two distinct domains — retail and education — into a single analytical workspace. The retail component examines superstore sales performance, while the education component explores student survey responses and university admissions data to surface enrollment patterns and applicant behavior.

## Folder Structure

```
Retail Store/
├── Project-1.pbix                      # Main Power BI dashboard
├── Project 1.pdf                       # Exported PDF report
├── Superstore Sales.xls                # Retail sales dataset
├── Student Survey.xlsx                 # Student survey response data
├── University Admissions-4.xlsx        # University admissions dataset (version 4)
├── University Admissions.xls           # University admissions dataset (original)
└── University Applications Charter.xlsx  # University applications reference data
```

## Key Insights

- **Retail Sales Performance** — Sales, profit, and category breakdown from the Superstore dataset
- **Student Survey Analysis** — Response distributions across demographic and academic dimensions
- **Admissions Trends** — Application and acceptance patterns across universities and programs
- **University Applications** — Volume and outcome data across institutions and academic years
- **Cross-Domain Patterns** — Identifying behavioral and demographic trends spanning consumer and student populations

## Data Sources

| File | Description |
|------|-------------|
| `Superstore Sales.xls` | Retail transaction data including product, region, and profit fields |
| `Student Survey.xlsx` | Survey responses from students on academic and lifestyle factors |
| `University Admissions-4.xlsx` | Admissions data including applicant counts, acceptance rates, and program details |
| `University Admissions.xls` | Original admissions dataset (baseline version) |
| `University Applications Charter.xlsx` | Reference data for university application processes and benchmarks |

## How to Use

1. Open `Project-1.pbix` in Power BI Desktop.
2. If prompted, update data source paths to point to the files in the same folder.
3. Refresh the data model to load all datasets.
4. Navigate between report pages to switch between retail and education views.
5. Apply slicers for region, category, university, or survey dimension as needed.
6. Refer to `Project 1.pdf` for a static snapshot of the key report visuals.
